# v0.12.2 vocabulary wave — 2026-10-17

Branch `v0.12.2-vocabulary`. Implements design items 2 and 3 of
`docs/vocabulary-extensions-design.md` (PR #14 / issue #5): the two
additive vocabulary terms, their SizeEval/gate rules, and the first
migrations. Both are **downstream-inert by construction** (additive
attributes the pinned generator ignores) — safe alongside the
parallel convergence round. PDF facts verified against **IEEE Std
1278.1-2012.pdf**.

## Item A — `countExpression` gains `product()` (design item 2)

**PDF truth** — Table 192 (Gridded Data PDU) where-clause: *"G is the
number of grid points in the PDU, which is V ∏(k=1..N) Nk; V is the
vector dimension; Nk is the number of points in Axis k"*. Derived,
never stored.

**Syntax** (one function form, quoted dotted path — the quotes make
the path a literal under expression evaluation):

```xml
<objectlist countExpression="vectorDimension * product('gridAxisDescriptors.numberOfPointsOnXiAxis')">
```

- **SizeEval:** `arith` binds `product('listField.elementField')` over
  the values dict's list (ints or maps; the product runs over the
  per-element field).
- **check_consistency gate C:** `product` whitelisted as the one
  function keyword; the quoted single-dotted-path arg validated —
  first hop an objectlist attribute, the field present on the declared
  concrete element (`initialClass` is the variant carrier; the bare
  classRef name is an abstract parent, not a wire element). Both
  `GridAxisDescriptorFixed` and `-Variable` carry the field; the Fixed
  variant is the declared carrier.
- **validate.py gate 8l:** empty PDU (V=0, no axes → G=0) = **512
  bits** — Table 192's fixed part exactly; axes 4×2 at V=1 → G=8
  (total 512 + 2×160 + 8×32); at V=3 → G=24. Records evaluate at the
  declared carriers' sizes (GridAxisDescriptor 160, GridData 32).
- Replaces the corrections wave's `isDynamicListLengthField` parking
  on `gridDataRecords`; retires the downstream `("GriddedDataPdu",
  "gridDataRecords")` FIELD_OVERRIDES entry when the generator
  consumes the expression.

## Item B — `derived="true"` on count mirrors (design item 3)

**Semantics** (v1 binding): the field is computed state — never
instance state, never caller-settable, still serialized on the wire —
with value = the cardinality of the list(s) whose `countFieldName`
names it. Orthogonal to `hidden` (derived counts are also
marshaller-managed; both markers present).

**Migration — 92 fields**, enumerated mechanically (hidden count that
is a list-count target) minus four ruled exclusions: the SM/SMWR
datum counts, minefield counts, EE/UA emitter/beam/target counts, IFF
layer counts, grid axis/data counts, DE Area Aimpoint counts,
EntityState(Update)/Detonation VP counts, logistics supply types,
aggregate counts, IO record counts, IsGroupOf, ArticulatedParts,
record-specification/attribute-set counts, DataQuery/Datum
specifications, IFFDataSpecification, SilentEntitySystem appearances,
and `StandardVariableSpecification.numberOfStandardVariableRecords`
(issue #9's first finding — progress noted on the issue).

**Excluded by ruling** (byte/formula lengths stay hidden-only pending
any future `derivedExpression` design):

| Field | PDF basis |
|---|---|
| `Attribute.recordLength`, `StandardVariableRecord.recordLength` | §6.2.83 b) 2): 6 + K + P with 64-bit pad — a formula, not a cardinality |
| `TimeSpacePositionInformationPdu.systemSpecificDataLength` | §9.4.2: "N is the number of octets of system-specific data" |
| `IntercomControlPdu.intercomParametersLength` | Table 179: "Intercom Parameters Length (K) — 32-bit unsigned integer" with the block at "8K" bits — K octets, not records |

**Gate C2** (new, in check_consistency): every `derived="true"`
attribute must have a primitive child, no `defaultValue`, also be
`hidden`, and be named by at least one list count. Three
`defaultValue="0"` markers were removed from migrated counts
(DirectedEnergyAreaAimpoint ×2, EntityDamageStatusPdu) — a computed
count has no default. The ≥1 (not exactly-1) reference rule is the
MinefieldDataPdu precedent: its dataFilter-gated per-mine lists all
reference `numberOfMinesInThisPdu` (the primary list is
`mineLocation`).
